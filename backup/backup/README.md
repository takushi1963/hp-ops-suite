# バックアップシステム概要（Backup System Overview）

このディレクトリは、HP ADS-B サーバのバックアップ／復旧システムを説明します。  
**人間**と**ChatGPT**が「貼り付け一発で状況理解」できることを目的にしています。

---

## このシステムがやっていること（What this system does）

バックアップは **3層** で守ります。

1. **フルディスク・イメージ（dd）**
   - SSD/ディスク故障など「完全損失」対策

2. **ファイル差分バックアップ（rsync）**
   - OS破損、設定ミス、誤操作からの復旧向け

3. **設定・スクリプトのソース管理（Git）**
   - バックアップの“仕組み”自体を復元可能にする
